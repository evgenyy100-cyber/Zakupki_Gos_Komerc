## Что выяснили про источники данных (проверено 25.11.2026)
- **FTP ЕИС отключён с 01.01.2025.** Раздел «Открытые данные» ведёт на тот же отключённый FTP.
- **Официальный машинный канал — SOAP-сервис `getDocsIP`.** Нужен личный токен; по разведке стороннего проекта (krein15/zakupki-parser, docs/recon.md, октябрь 2026) портал выдачи токенов требует **квалифицированную электронную подпись (КЭП)** и ГОСТ-TLS, одного входа через Госуслуги мало. В голосовом разговоре Claude ошибочно сказала, что хватит Госуслуг, — это поправлено здесь.
- **Без регистрации работает сам сайт zakupki.gov.ru:** расширенный поиск (слова со словоформами, 44-ФЗ / 223-ФЗ, цена, регион по коду КЛАДР, этап «Подача заявок») и полный XML извещения 44-ФЗ по номеру (`/epz/order/notice/printForm/viewXml.html?regNumber=…`). Сайт ограничивает частоту запросов (HTTP 429), поэтому массовый автоматический сбор нежелателен.
- **Платные посредники** (ГосПлан API, DaMIA, TenderFeed, ofdata) — вариант на потом.
- **Коммерческих торгов в ЕИС нет**; списки на B2B-Center, Фабриканте и т. п. часто видны без входа, но автоматически собирать их без разрешения площадок нельзя.

## Решение: «одно нажатие» вместо сбора программой
Первоначальная идея — ассистент сам прочёсывает площадки по фильтрам. Без доступа и без нарушения правил площадок выбран полуавтоматический путь:
1. Приложение по фильтрам **собирает ссылку на поиск в ЕИС** и открывает её (кнопка «🔎 Открыть поиск в ЕИС по этим фильтрам»).
2. Пользователь на странице выдачи или карточки закупки нажимает **закладку браузера «📥 В Умные закупки»**:
   - на странице выдачи — берутся все закупки страницы (номер, объект, способ, этап, НМЦК, заказчик, даты размещения и окончания подачи заявок);
   - на карточке 44-ФЗ — закладка запрашивает с того же сайта XML извещения и берёт ещё позиции (ОКПД2, количество, единица, цена за единицу), место поставки, площадку.
   Данные копируются в буфер обмена. Это одна страница, которую человек сам открыл, — не массовый сбор.
3. В приложении кнопка **«📥 Вставить из ЕИС»** добавляет закупки в раздел «Реальные закупки из ЕИС». Если браузер не даёт читать буфер, открывается поле для вставки (Ctrl+V).
4. В карточке реальной закупки пользователь вводит цену поставщика, доставку, прочие расходы и поставщика (название, ссылка, дата проверки) — приложение считает условную чистую прибыль, оборотный капитал и нехватку капитала. Пока нет цены поставщика, метка «Нужна цена поставщика».
5. Реальные закупки сохраняются в браузере (localStorage) и переживают перезапуск страницы.

Реализация — в `app/index.html` (текст закладки там же, в блоке `bmSource`). Проверено на сохранённых страницах ЕИС: страница выдачи (50 закупок) и XML аукциона с позициями.

## Ограничения текущей версии
- Закладка с XML работает для 44-ФЗ; для 223-ФЗ — только данные со страницы выдачи (XML 223-ФЗ запрашивается по guid, это следующий шаг).
- Регионы в ссылке на поиск — только три из списка фильтров (Москва и область, Санкт-Петербург, Татарстан); полный справочник КЛАДР — следующий шаг.
- Налог считается условно (УСН 6% / 15%); сводные метрики вверху пока по демо-примерам.
- Цены поставщиков и доставка вводятся вручную.
- Закладку нужно один раз перетащить на панель закладок (браузер на компьютере).
