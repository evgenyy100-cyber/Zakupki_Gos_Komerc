# Zakupki_Gos_Komerc — «Умные закупки»

Прототип помощника по госзакупкам и коммерческим закупкам: найти закупку, посчитать себестоимость, условную чистую прибыль и нужный капитал.

**Открыть:** `app/index.html` в браузере (Chrome, Яндекс, Edge).

## Как работать с реальными закупками (без токенов и регистрации)
1. Задать фильтры и нажать **«🔎 Открыть поиск в ЕИС по этим фильтрам»** — откроется zakupki.gov.ru.
2. Один раз перетащить кнопку **«📥 В Умные закупки»** (раздел внизу панели фильтров) на панель закладок.
3. На странице выдачи или карточки закупки в ЕИС нажать эту закладку — данные скопируются.
4. Вернуться в приложение и нажать **«📥 Вставить из ЕИС»**, затем ввести цену поставщика и доставку.

Подробности, ограничения и решения — `docs/conversations/2026-11-25.md`; исходные требования — `docs/conversations/2026-10-27.md`.

Расчёт налога условный и не является налоговой консультацией.
