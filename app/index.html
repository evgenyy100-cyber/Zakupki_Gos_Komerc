📥 Кнопка «В Умные закупки» для браузера

Закладка-кнопка, которую нажимают на сайте ЕИС: она копирует найденные закупки, а здесь вы их вставляете.

📥 В Умные закупки

Если кнопка не копирует — выделите код в поле ниже вручную (долгое нажатие → «Выбрать всё» → «Копировать»):

На телефоне (Chrome, Android):

  1. Нажмите «📋 Скопировать код закладки».
  2. Откройте любую страницу, например zakupki.gov.ru, нажмите ⋮ → ☆ (добавить в закладки).
  3. ⋮ → «Закладки» → у новой закладки ⋮ → «Изменить». Название: уз. Адрес: сотрите и вставьте скопированный код. Сохраните.
  4. На странице ЕИС нажмите на адресную строку, наберите уз и выберите закладку со звёздочкой в подсказках. Из списка закладок она не сработает — только через адресную строку.
  5. Появится плашка «Скопировано закупок…». Вернитесь сюда → «Вставить из ЕИС» → долгое нажатие в поле → «Вставить» → «Добавить».

На компьютере: перетащите жёлтую кнопку на панель закладок (Ctrl+Shift+B — показать панель).

Порядок работы:

  1. Откройте поиск в ЕИС кнопкой выше.
  2. На странице с результатами или на карточке закупки нажмите закладку «📥 В Умные закупки».
  3. Вернитесь сюда и нажмите «Вставить из ЕИС».

На странице выдачи закладка берёт все закупки страницы (номер, объект, цену, заказчика, срок подачи). На карточке 44-ФЗ — ещё и позиции с ОКПД2, количеством и местом поставки из официального XML извещения. Это одна страница, которую вы сами открыли, а не массовый сбор.

Реальные закупки добавляются из ЕИС закладкой «📥 В Умные закупки»: номер, объект, НМЦК, заказчик и срок берутся с сайта, цену поставщика и доставку вы вводите сами. Демонстрационные примеры ниже вымышленные. Налог считается условно (УСН 6% / 15%) — это не налоговая консультация. Сводка вверху пока считается по демо-примерам.
